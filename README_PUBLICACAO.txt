GARDINI SERVIÇOS RESIDENCIAIS — PACOTE PARA PUBLICAÇÃO

- assets/anuncio-gardini.png

Antes de publicar, configure no final do index.html:
const WHATSAPP_NUMBER = "55DDDNUMERO";
Exemplo de formato: 5511934094906 (somente números).

Para Netlify Drop, envie a pasta Gardini_Publicacao ou o arquivo ZIP.
Para cPanel, envie o conteúdo desta pasta para public_html.
